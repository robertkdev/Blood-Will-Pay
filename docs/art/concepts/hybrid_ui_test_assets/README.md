## Shared Prompt Contract

All assets were generated with built-in ImageGen and used the approved gothic
forest title, the current player-facing planning screen, or the prior
all-hardcore preview as explicitly labeled references.

Shared constraints:

- Palette: xerox black, dirty bone, dried oxblood, dark iron, and restrained
  old brass.
- Preserve the wet gothic world; never turn units, board cells, health bars, or
  combat VFX into paper collage.
- Use print texture only for framing, authored messaging, price, purchase, and
  outcome punctuation.
- Keep all functional copy clean and exact.
- No concert audience, literal band performance, unrelated logos, watermarks,
  pseudo-copy, fantasy parchment scrolls, neon, or full-screen scrapbook noise.

## Review

`C:\Users\Flipm\.codex\visualizations\2026\07\29\019fabb0-baad-7c53-ac74-0741d0e3b524\hybrid-ui-assets-vdh-runs\hybrid-ui-assets-c924a53481\packet`

The pack is evidence for choosing an art direction. It is not permission to
drop these raster mockups directly into Godot. Production work still needs
exact component measurements, deterministic crops and masks, state variants,
nine-slice audits, accessibility checks, motion tests, and fresh runtime
captures at the supported viewport matrix.

Independent clean-context visual review passed the pack for concept direction,
not runtime acceptance. The main production risks are small menu type at
compact sizes, keeping the pressure strip genuinely brief, proving result
screens with populated values, and reducing the shop card's ragged paper
perimeter so the portrait frame remains more gothic than printed.
