Shared implementation: Python package `visual-debug-harness>=0.2.0`.

`python -B addons/art_preview/preview.py <operation>` delegates to `vdh-art`.
The runtime under `addons/vdh_art_preview` is generated by `vdh-art --project <root> install`;
its version and hashes are checked before starting. Update the shared package,
then reinstall the managed runtime. Do not fork or edit its generated files.

Only `preview_adapter.gd`, `profile.json`, and the tiny compatibility scene/host
belong to this project. They bind actual game components and isolate fixture state.
Commands: prepare, launch, run, describe, apply, geometry, capture, evidence, stop, close.
`prepare --reference <image> --output <new-external-directory>` emits a required
reference/actual visual manifest. `apply --settings <json> --expected-revision N`
waits for a fresh pair. MCP exposes equivalent `godot_art_*` tools.

Follow this project's launch/hydration rules. Private saves and fullscreen output
are mandatory. No tool panel is drawn. A valid capture is not an aesthetic pass;
presets affect preview instances and must be authored into the shipping scene separately.
